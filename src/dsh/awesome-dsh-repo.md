# awesome-dsh-repo

## deepseek-harness⭐

[deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)

deepseek official agent

```bash
# run
npx @deepseek-ai/dsh web

# install
npm install -g @deepseek-ai/dsh

```

> 注意，使用 pnpm 安装可能出现问题。如果 pnpm 安装后启动出现问题，卸载转用 npm 安装即可。

## dsh-web-ui⭐

[dsh-web-ui](https://github.com/zhu1090093659/dsh-web-ui)

a comperhensive, better web ui for dsh

```bash
# install
dsh plugin --profile web add @linxin666/dsh-web-ui-all@latest

# approve pnpm build if [ERR_PNPM_IGNORED_BUILDS] Ignored build scripts: cloudflared@0.7.3, cpu-features@0.0.10, node-pty@1.1.0, ssh2@1.17.0
pnpm approve-builds
```

## awesome-dsh-plugin⭐

[awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin)

a place where you find nice dsh plugins. Installable to the web ui.

```bash
# install
dsh plugin --profile web add dshmarket
```
