# campus-network

傻逼校园网真的很傻逼，又贵又难用。
校园网最低的套餐69rmb一月，算下来828rmb一年。主要包含两个东西，流量550GB，wifi 认证 宽带200mbps下行50mbps上行。
这流量垃圾得很，有wifi的地方用不着，没wifi的地方用不出来，一个月大概只能用出30GB左右。
这wifi 认证 宽带也很垃圾。教室人多照样卡。没有全校园覆盖。宿舍网速确实能到200mbps。但要是只要寝室有一个人下东西，剩下六个人的网络质量都会出问题，就都别想好好玩游戏了，甚至别的寝室也会影响你的网络质量。
这差不多是把1份宽带拆6份卖，相当于4968rmb一年的逆天价格。
嫌钱多就买吧。
