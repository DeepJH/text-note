# snoring-manifesto

关于呼噜问题，我需要补充一下我的视角的信息。首先最基本的，我听呼噜，被无法入睡，我承担了大量损失。甚至最严重的时候晚上大部分时间都没睡，只睡2小时，寻求补偿被拒，这是有记录的。
并且我也尽可能主动退让。反转床位避让是我主动提出，但是被拒绝后被动做的。我也长期自费买顶级的耳塞。长期戴降噪耳机甚至出现过耳后淋巴肿大。也主动尝试换宿舍。
我认可对上次对他的措施较为过分的看法，
我也知道刘汉为此有所作为和不作为。
但是总之呼噜问题确实是非常严重的，不然也不会到这个地步，我也不想再折腾了，我并不比他更轻松！
如果刘汉愿意，请提醒他换床位。隔那么远的话我认为我目前的降噪装备是绰绰有余的。
如果不愿意，我认为租房经费对于反呼噜经费来说也是绰绰有余的。
