## 参数

llama.cpp cli 的**15 个 最常用、最核心的参数**。日常使用中，只需掌握这些就足够覆盖大部分场景：

### 1. 核心必用参数

| 参数 | 常用示例 | 作用与使用场景 |
| --- | --- | --- |
| **`-m`** | `-m ./model.gguf` | **模型路径**。指定要加载的 GGUF 模型文件。 |
| **`-ngl`** | `-ngl 99` 或 `-ngl 30` | **显存层数**。GPU 卸载层数。显存够大设为 `all` 或 `99` 全显存运行；显存不够设为较小数字（如 `30`）走 CPU+GPU 混合。 |
| **`-c`** | `-c 8192` | **上下文长度**。决定模型能记住多少历史对话。显存小建议设 `4096`，显存大可设 `8192` 或更高。 |
| **`-cnv`** | `-cnv` | **对话模式**。开启交互式聊天，像 ChatGPT 一样在命令行多轮对话。 |

---

### 2. 性能与显存优化参数

| 参数 | 常用示例 | 作用与使用场景 |
| --- | --- | --- |
| **`-fa`** | `-fa` | **Flash Attention 优化**。强烈建议加上！能大幅降低显存占用并提升长文本速度。 |
| **`-t`** | `-t 8` | **CPU 线程数**。不指定时自动匹配，手动指定时设为 CPU 的**物理核心数**性能最好。 |
| **`-ctk / -ctv`** | `-ctk q8_0 -ctv q8_0` | **KV 缓存量化**。显存紧张时的“救星”！将默认的 `f16` 改为 `q8_0` 或 `q4_0`，可以大幅挤出显存。 |
| **`--context-shift`** | `--context-shift` | **无限长对话**。当对话超出 `-c` 的限制时，自动挤掉最早的对话继续聊，防止程序崩溃。 |

---

### 3. 生成效果控制参数

| 参数 | 常用示例 | 作用与使用场景 |
| --- | --- | --- |
| **`--temp`** | `--temp 0.7` | **温度 (随机度)**。`0.0` 用于写代码、数学推理（结果确定）；`0.7~0.8` 用于日常对话；`1.0+` 用于文学创作。 |
| **`--min-p`** | `--min-p 0.05` | **采样切片**。自动过滤极低概率的怪异词汇，建议配合 `--temp` 保持开启。 |
| **`--repeat-penalty`** | `--repeat-penalty 1.1` | **重复惩罚**。设为 `1.1` 到 `1.2` 能有效防止模型车轱辘话反复说。 |
| **`-j / -jf`** | `-j '{"type":"object",...}'` | **JSON Schema 强约束**。强制模型 100% 返回合法 JSON 格式，提取结构化数据时必用。 |

---

### 4. 多模态与特殊控制参数

| 参数 | 常用示例 | 作用与使用场景 |
| --- | --- | --- |
| **`-hf`** | `-hf Qwen/Qwen2.5-7B-Instruct-GGUF:Q4_K_M` | **HF 直接加载**。无需手动下载模型，指定仓库名即可自动下载并运行。 |
| **`--mmproj`** | `--mmproj ./mmproj.gguf` | **视觉投影矩阵**。运行看图模型（如 LLaVA/Gemma-Vision）时必填。 |
| **`--image`** | `--image ./pic.jpg` | **传入图片**。搭配 `--mmproj` 使用，让模型分析本地图片。 |

## 常用命令

1. 运行

    ```bash
    llama cli \
    -m "./Qwen3.5-9B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf"
    -ngl 99 \
    -c 80000 \
    -cnv \
    -fa on
    ```

2. 指定显卡

    ```bash
    llama-cli --list-devices
    # 加上 --device Vulkan0 参数
    ```

## FAQ

Q1: 怎么`跑分`？
A1: 如果要测速，则`要用 llama-bench` 而不是 llama-cli。
    例如：

```bash
llama-bench \
-m "/run/media/deepjh/500GB矿盘A/FILE/AI/LuffyTheFox/Hermes3.6-35B-A3B-Uncensored-Genesis-V7-APEX-Compact.gguf" \
-ngl 17 \
-fa on
```

Q2: 为什么 -ngl `调多了就炸显存`了？`不自动`分配吗？
A2: 没有。`要自己定`，写的加载多少就是多少，`多了会爆`。要`尽可能大`。也有脚本可以自动调。

Q3: ngl`外`的部分在哪里？
A3: `内存`。

Q4: 设定好上下文大小，运行没有炸显存。后面是不是也不会炸？
A4: 对。
