# llama-server-cheat-sheet

llama.cpp server 的**15 个 最常用、最核心的参数**。日常使用中，只需掌握这些就足够覆盖大部分场景：

> 未实践验证，可能存在问题。

## 1. 基础与服务配置参数

| 参数 | 常用示例 | 作用与使用场景 |
| --- | --- | --- |
| **`-m` / `--model**` | `-m ./model.gguf` | **模型路径**。指定服务需要加载的 GGUF 模型文件。 |
| **`--host`** | `--host 0.0.0.0` | **监听地址**。默认仅本地（`127.0.0.1`）可访问；若要提供给局域网或外部调用，需设为 `0.0.0.0`。 |
| **`--port`** | `--port 8080` | **服务端口**。指定 HTTP 服务监听的端口，默认为 `8080`。 |
| **`-a` / `--alias**` | `-a gpt-4o-mini` | **模型别名**。定义在 OpenAI API 接口（如 `/v1/chat/completions`）中调用的 `model` 名称。 |
| **`--api-key`** | `--api-key sk-xxxx` | **鉴权密钥**。设置请求 API 时所需的 Bearer Token 或 API Key，防止未授权访问。 |

---

## 2. 显存与性能优化参数

| 参数 | 常用示例 | 作用与使用场景 |
| --- | --- | --- |
| **`-ngl` / `--gpu-layers**` | `-ngl 99` | **GPU 卸载层数**。显存充足时填 `all` 或 `99` 全显存跑；显存有限时填较小数字（如 `30`）分摊到 CPU。 |
| **`-fa` / `--flash-attn**` | `-fa` / `-fa on` | **Flash Attention 优化**。建议必开！能显著降低 KV 缓存显存占用并提升长文本处理速度。 |
| **`-c` / `--ctx-size**` | `-c 8192` | **上下文长度**。决定服务单次会话最大能处理的 Token 长度（包含 Prompt + 生成内容）。默认为模型元数据自带值。 |
| **`-ctk / -ctv`** | `-ctk q8_0 -ctv q8_0` | **KV 缓存量化**。显存告急时的救星！将默认的 `f16` 压缩为 `q8_0` 或 `q4_0`，大幅节省 KV Cache 显存。 |
| **`-t` / `--threads**` | `-t 8` | **CPU 线程数**。在 CPU 参与计算时使用，建议设置为机器的**物理 CPU 核心数**以获得最佳性能。 |

---

## 3. 并发与推理控制参数

| 参数 | 常用示例 | 作用与使用场景 |
| --- | --- | --- |
| **`-np` / `--parallel**` | `-np 4` | **并发 Slot 槽位数**。决定服务器能同时并发处理多少个独立请求。注意槽位数越多，对显存（KV Cache）要求越高。 |
| **`-cb` / `--cont-batching**` | `-cb` | **连续批处理**。默认开启，实现多用户动态 Batch 挤压与处理，极大提高高并发下的总体吞吐量。 |
| **`--context-shift`** | `--context-shift` | **无限长对话机制**。当单次会话达到 `-c` 长度上限时，自动移除最早的 Token 历史继续生成，避免程序爆显存崩溃。 |

---

## 4. 多模态与高级功能参数

| 参数 | 常用示例 | 作用与使用场景 |
| --- | --- | --- |
| **`-mm` / `--mmproj**` | `-mm ./mmproj.gguf` | **视觉投影矩阵**。在运行视觉/多模态模型（如 LLaVA 等看图模型）时必配的文件路径。 |
| **`--jinja`** | `--jinja` | **Jinja 模板解析**。默认开启，可完美匹配官方模型的对话格式，也是开启 OpenAI 函数调用（Tool Call）的基础。 |

---

## 💡 3 个常用服务启动模板

**1. 单人/开发测试配置（全显存加速跑）：**

```bash
llama-server -m ./model.gguf -ngl 99 -fa -c 8192 --host 0.0.0.0 --port 8080

```

**2. 多人并发/轻量服务器配置（带密钥保护、开启 4 并发）：**

```bash
llama-server -m ./model.gguf -ngl 99 -fa -c 16384 -np 4 -ctk q8_0 -ctv q8_0 -a gpt-3.5-turbo --api-key sk-my-secret-key --host 0.0.0.0 --port 8080

```

**3. 多模态看图服务配置：**

```bash
llama-server -m ./vision-model.gguf -mm ./mmproj.gguf -ngl 99 -fa -c 8192 --host 0.0.0.0 --port 8080

```
