# idea-brief-clock

## 任务

制作一个安卓时钟 app brief clock 的 MVP。它和常规闹钟相比，主要带有特色功能 `brief alarm`， `nap roulette`。并确保代码优质（例如正确，可读性强，简洁，模块化，健壮，可测试，可维护，可拓展，性能合理，安全，工程化良好）。

## 做法

在 github 上寻找成熟完善的基础安卓时钟项目并进行改造（必须star数>=1k，如果没有，则提醒我人工审核）。并且注意`包括但不限于``许可证`等问题。

## 特色功能

1. `brief alarm`
    按住录音设为闹钟铃声
    识别和换音tts自定义默认前缀
    常规闹钟功能，设置系统闹钟，权限，日历
    创意工坊 用户加标签
2. `nap roulette`
    手枪3d动画
    设定睡多少时间，然后开赌，在时间内停止睡眠视为失败
    开枪音效
    扳机音效
    排行榜（录音为证据）
统计
    包括睡觉轮盘赌等信息
反馈
    快速分享想法
